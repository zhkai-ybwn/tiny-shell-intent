## 维护约定

- 主题使用中文；保留 TinyShell、PowerShell、PSReadLine、Model2Vec、ADR 等技术名称。
- 当前态文档不在文件名中加入日期或版本后缀，修订历史由 Git 管理。阶段记录使用 `YYYY-MM-DD-中文主题.md`。
- README 提供简介、最短运行路径和导航；细节分别维护在职责对应的文档中。
- 实现变化同步更新对应正式文档和现状；有关键取舍时补充 ADR，不为每次小修复建立决策记录。
- 测量数据必须说明实现语言、样本、缓存、内存口径及来源；没有运行证据时标注待验证。
- 模型自带 README 保持原位，根目录 JSON 评测产物和数据文件继续使用现有路径。
