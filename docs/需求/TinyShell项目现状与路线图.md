# TinyShell 项目现状与路线图

> 核对日期：2026-10-22。代码审查五项修复已完成，C#／Python 回归和非物理按键验证已执行；未安装至用户目录，真实终端交互仍待手动验收。

## 当前交付

项目已包含 Python 原型和 .NET 8 原生 PowerShell 模块。用户侧交付入口为 `modules/TinyShell`，Python 用于原型研究与对照评测。

| 部分 | 当前实现 | 事实源 |
|---|---|---|
| 检索引擎 | 唯一规则短路、模糊匹配、静态向量、融合约束与拒绝门控 | `src/TinyShell.Core/IntentEngine.cs` |
| 本地模型 | Safetensors 权重读取、WordPiece 分词与静态向量编码 | `src/TinyShell.Core/Storage/`、`Tokenizer/`、`Matchers/ModelMatcher.cs` |
| PowerShell 接口 | `Get-TinyIntent`、`Initialize-TinyIntent` | `src/TinyShell.PowerShell/` |
| 终端交互 | 快捷键注册、冲突提示、风险菜单、缓冲行替换、注销与模拟入口 | `modules/TinyShell/TinyShell.psm1` |
| 数据 | 51 个意图、92 条查询、跨语言对照 fixture | `data/` |
| 分发 | Release 构建、资源组装、当前用户安装 | `scripts/publish_module.ps1`、`scripts/Install-TinyShell.ps1` |

PowerShell 模块清单版本为 `1.0.0`，Python 项目版本为 `0.1.0`，属于两个交付入口；不能用其中一个推断另一个的发布状态。仓库包含实现不代表已经完成目标环境发布。

## 后续方向

以下是基于现状整理的建议顺序，尚未作为已批准的新功能计划：

1. 在干净 PowerShell 会话完成源码构建、安装与真实终端手动验收。
2. 在目标机器重新测量冷启动、无缓存检索及 PowerShell 进程增量内存，形成可复现记录。
3. 正式分发前核对 SDK、模块版本、依赖和包内文件，保存对应构建证据。
4. 如需扩展意图或语言支持，先明确样本与验收要求，再同步知识库、两个实现和对照用例。
