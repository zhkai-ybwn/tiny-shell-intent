# TinyShell 需求与验收标准

> 状态：当前产品边界与验收目标。测试存在或历史通过不表示本轮已验收。

## 产品范围

面向 Windows PowerShell 7.4+ 用户，将有限命令知识库中的英文自然语言、别名和拼写错误映射为候选命令。以本地建议和人工审查为交互方式，使用发布包时无需 Python、GPU、外部模型服务或独立后台进程。

当前知识库覆盖进程、文件系统、网络、系统、环境变量、压缩和版本控制七类，共 51 个意图。Git 等外部工具仅支持明确收入知识库的范围；任意脚本生成、自动执行、多步自主操作及通用中文理解不属于已交付能力。

## 功能与验收

| 功能 | 验收要求 |
|---|---|
| 精确别名 | `ll` 对应 `file_list`，`git s` 对应 `git_status`；仅唯一无歧义精确匹配短路 |
| 混合检索 | 支持四种模式，默认 hybrid；处理自然问法、拼写错误和带参数查询 |
| 意图约束 | 区分本地监听与远程连通、停止与启动、运行时间与重启、复制与删除、单文件与目录范围 |
| 域外拒绝 | 空白、符号、代码、低置信度及不支持的外部工具输入不作为可操作候选交付；调试候选只供检查 |
| 参数 | PID、端口、路径等按意图槽位抽取；IPv4／URL 不被拆成错误数值；字符串按 PowerShell 字面量规则渲染 |
| 完整性 | 缺少必要参数或残留占位符时 `IsComplete=false`，菜单显示 `[NEEDS PARAMS]`；用户仍需自行补全 |
| 风险 | 输出 `safe / warning / dangerous`；最终命令的风险扫描不能把知识库已标记的风险降级 |
| 终端菜单 | 默认 `Alt+s`，最多显示三个候选；选择仅替换缓冲行；`Esc/Enter` 取消并保留输入 |
| 环境兼容 | 当前会话已有命令显示提示，仍可展示建议；快捷键冲突默认不覆盖，显式 `-Force` 可覆盖 |
| 生命周期 | 可注册和注销快捷键；安装脚本不自动编辑用户配置文件 |

风险标签和安全渲染是实现约束，不代表对所有输入的形式化安全证明。插件允许用户选择尚未补全的模板，完整性标签不等于禁止填入。

## 质量与资源目标

| 指标 | 目标或现有测试门槛 |
|---|---|
| 用户侧 Python / GPU / 网络 / 独立后台依赖 | 0 |
| 模型资源体积 | 目标不超过 8 MiB；历史文档写作 MB，按字节口径解读 |
| 完整发布目录 | 目标尽量不超过 15 MiB |
| 内存 | 目标增量尽量不超过 30 MiB；C# 测试断言针对托管堆，进程工作集另测 |
| 无缓存热态检索 P95 | C# 基准测试断言不超过 10 ms |
| 域内准确率 | C# 现有测试断言 Top-1 ≥ 88%，Top-3 ≥ 99%；产品目标 Top-3 为 100% |
| 负样本 | 固定负样本集全部拒绝；不能外推为任意域外输入均可识别 |

测试目标、历史结果和当前结果须分别记录。样本与执行方式见[测试与验收指南](../测试验证/TinyShell测试与验收指南.md)。
