# ADR-0001：采用进程内静态向量检索并仅替换命令缓冲区

> 状态：已体现在当前代码中的决策，2026-10-22 整理补录；不代表该日首次作出或新增批准。

## 背景

项目由 Python 语义检索原型演进为 PowerShell 插件。用户侧目标是离线、轻量和低延迟，避免维护独立 Python 服务或引入大型推理运行时；命令可能包含修改或破坏性操作，建议与执行需要保留人工审查环节。

## 决策

- 使用 .NET 8 核心类库和 PowerShell Cmdlet，在宿主进程内加载本地知识库与模型。
- 使用 Model2Vec 静态词向量，直接读取 Safetensors、执行 WordPiece 分词及向量检索，结合规则和模糊匹配。
- 保留 Python 原型与固定对照数据，支持行为比较与回归。
- 默认使用 `Alt+s` 显式触发建议，降低 Ctrl+i 与 Tab 键码冲突的影响。
- 用户选择后只调用 PSReadLine 缓冲替换，不调用 AcceptLine 或自行执行命令。
- 风险标记、缺参提示、拒绝门控和参数安全渲染在交付候选前处理。

## 权衡与后果

用户端不需要 Python、网络模型服务或独立后台进程，部署单位为包含 DLL、知识库和模型的完整模块目录。构建端仍需要 SDK 和依赖还原条件。

自实现分词和权重读取减少了推理依赖，同时带来模型格式兼容、数值一致性和维护成本；模型更换需要对照验证。Python 与 C# 两份逻辑也存在漂移风险，需要同步检查。

有限知识库与静态语义检索可以建议已定义命令，无法据此承诺任意语言理解、任意命令生成或域外识别。风险标签不能代替用户检查，未补全模板仍可能被填入缓冲行。
